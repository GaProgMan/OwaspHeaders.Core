Version 11 is a major release with breaking changes: .NET 8 and .NET 9 support is dropped, Expect-CT is removed, the configuration setters are internal, and configuration moves to app.UseSecureHeadersMiddleware(opt => ...), with the build-then-pass API deprecated for removal in version 12.

Building a project which references this package now writes an agent skill for coding agents into your repository, in .agents/skills/owaspheaders-core/ and .claude/skills/owaspheaders-core/, hidden from git by a .gitignore. It is skipped on CI, and <OwaspHeadersCoreAgentSkill>false</OwaspHeadersCoreAgentSkill> turns it off. Details: https://gaprogman.github.io/OwaspHeaders.Core/agent-skills

Full changelog: https://gaprogman.github.io/OwaspHeaders.Core/changelog
